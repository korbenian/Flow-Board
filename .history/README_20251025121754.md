# 🚀 Personal Dashboard App

**Fullstack web-приложение**, созданное для управления задачами, чтения статей и отслеживания пользовательской активности.  
Проект выполнен на базе **Next.js**, **Firebase** и **Auth.js**, с поддержкой авторизации через **Google** и **GitHub**.

---

## ⚙️ Функционал

### 🔐 Авторизация

- Вход через **Google** или **GitHub** с помощью `Auth.js`
- После входа пользователь попадает в свой **Dashboard**

---

### 📊 Dashboard

- Отображает основную информацию о пользователе
- Визуализирует данные (прогресс, активность, метрики)
- Современный адаптивный дизайн с использованием **Tailwind CSS**

---

### 📰 Articles

- Раздел со статьями
- Возможность просматривать контент и добавлять новые материалы (в будущем — поиск и категории)

---

### ✅ Tasks

- Создание, редактирование и удаление задач
- Статусы выполнения (To Do / In Progress / Done)
- Сохранение данных в **Firebase Firestore**

---

### 👤 Profile

- Отображение информации о пользователе
- Возможность редактировать имя, псевдоним, возраст и другие поля
- Все данные сохраняются в Firestore

---

## 🧱 Технологии

- **Next.js 15**
- **React 19**
- **Tailwind CSS**
- **Auth.js**
- **Firebase / Firestore**
- **TypeScript**
- **Framer Motion** (анимации)
- **Recharts** (графики)
